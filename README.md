Berikut adalah latihan Excel dari **BelajarExcel.id** melalui halaman **XL Test**: [https://belajarexcel.id/xl-test/](https://belajarexcel.id/xl-test/). Latihan ini digunakan untuk mengukur kemampuan Excel tingkat **dasar hingga menengah**, yang di dalamnya berupa pengolahan teks, penggunaan rumus logika, pencarian data, perhitungan angka, pengolahan tanggal, serta analisis data sederhana menggunakan Microsoft Excel.
